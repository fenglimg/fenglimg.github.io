## 原始提示词

这个场景是照着下面这段提示词做的。我把它当作需求文档，逐条落到实现上：

```text
制作一个雨夜便利店街角小场景，以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观，没有任何 UI 界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质表现干净，轮廓明确，色彩柔和但富有夜景霓虹的层次感。

场景主体是一处日式便利店街角，便利店位于底座的视觉中心，外部有典型的日式街角元素：便利店招牌、玻璃橱窗、自动门、屋檐雨棚、门口地垫、自动贩卖机、自行车、雨伞架、垃圾桶、路灯、电线杆、电线、路牌、街角护栏、停车位、排水沟、积水路面、反光斑马线、小巷入口、空调外机、小型公告栏或海报栏等。街道不需要太大，但要有明确的街角转折感，像日本动画里常见的夜晚社区一角。

不要人物，但便利店内部一定要有足够内容，并且可以透过大面积玻璃窗清楚看到店内。店内可见典型便利店陈设，例如：整齐排列的货架、饮料柜、便当区、饭团和零食陈列、收银台、咖啡机、杂志架、宣传海报、店内灯箱、冰柜、关东煮柜台、地面导视、储物柜或后场门等。要让便利店内部显得明亮、温暖、真实、充实，与室外潮湿昏暗的雨夜形成鲜明对比，营造出非常典型的日式动画雨夜氛围。

美术风格重点强调：高精细建模、三渲二卡通渲染、清晰的轮廓线、细腻但简洁的材质层次、湿润的夜景反光、暖色室内灯光与冷色雨夜街景对比、浓厚的二次元日常场景感。整体气质应偏向安静、治愈、带一点都市夜晚孤独感但依然温暖，像一幕被定格下来的日本动画街角场景模型。

加入一些基础动效来增强生命力：持续降雨、屋檐滴水、地面积水波纹、便利店招牌或灯箱轻微闪烁、自动门偶尔开合、雨水沿玻璃滑落、街道路面积水反射灯光、远处交通信号灯微弱变化等。整体效果应像一个静止而精致的三维微缩世界，但带有恰到好处的细微动态，突出其三渲二、二次元、雨夜、便利店、街角、小巧精致的核心特征。
```

> [!NOTE]
> 提示词里写的是「不要人物」。第一版照做了，后来觉得街角少了点生活气息，又补上了几个 NPC，见文末「街坊们」一节。

> [!NOTE]
> 这个场景的定位是技术展示，没有为性能做取舍：桌面端固定 2 倍超采样，每帧大约要跑 30 次渲染。用集成显卡或手机打开可能会比较吃力。

## 一帧是怎么画出来的

整个场景大约 1800 行代码，只依赖 Three.js（r147）和它的两个官方示例脚本：轨道控制器和泛光后期。每一帧按下面的顺序渲染：

| 步骤 | 内容 | 作用 |
| --- | --- | --- |
| 1 | 阴影贴图 | 两盏店内点光源（各 6 个面）+ 一盏路灯聚光灯 |
| 2 | 法线通道 | 整个场景换成法线材质渲染一遍，供描边使用 |
| 3 | 镜像通道 | 从地面以下的镜像相机渲染一遍，用于湿地面反射 |
| 4 | 颜色通道 | 正常渲染，同时输出深度纹理 |
| 5 | 描边合成 | 用深度和法线找出轮廓线，叠加背景渐变和暗角 |
| 6 | 泛光 | `UnrealBloomPass`，让招牌和灯具周围产生光晕 |
| 7 | 最终合成 | 移轴景深、ACES 色调映射、边缘色散、冷暖分离调色、胶片颗粒 |

下面挑几个关键点展开。

## 三渲二：只有三档明暗的卡通着色

卡通渲染的核心，是把连续的明暗变化压成几个色阶。Three.js 的 `MeshToonMaterial` 接受一张渐变贴图（`gradientMap`），只要给它一张 3 个像素、并且关闭插值的贴图，光照就会被量化成「暗 / 中 / 亮」三档：

```js
var gradMap = new THREE.DataTexture(
  new Uint8Array([72, 72, 72, 255,  150, 150, 150, 255,  255, 255, 255, 255]),
  3, 1, THREE.RGBAFormat
);
gradMap.minFilter = gradMap.magFilter = THREE.NearestFilter;  // 关键：不插值，色阶才是硬边
gradMap.generateMipmaps = false;
gradMap.needsUpdate = true;
```

店里的物体额外加了一点同色的自发光，让室内看起来比室外亮一整档。暖色的店内和冷色的街道就这样拉开了对比。

## 描边：从深度和法线里找轮廓

最常见的描边做法是「外壳法」：把模型沿法线放大一圈、只渲染背面。但这个场景里大部分物体是方盒子，方盒子的面法线不连续，外壳在棱角处会裂开。所以我改用后期描边：先渲染一张法线图，再在全屏着色器里同时检查两种突变。

- **深度突变**：画出物体的外轮廓，以及前后物体的交界。
- **法线突变**：画出同一个物体上的折角，比如箱子的棱。

深度这里有个细节：如果直接比较相邻像素的深度差，斜着看的大块地面会被误判成边缘。改用深度倒数的二阶差分就能避开，因为平面上的深度倒数在屏幕空间里是线性的，二阶差分恒为 0：

```glsl
float invd(vec2 uv){
  float z = texture2D(tDepth, uv).x;
  return 1.0 / max(-perspectiveDepthToViewZ(z, uNear, uFar), 0.001);
}
// 平面上恒为 0，只有真正的断层才会被检测出来
float de = (abs(i1 + i2 - 2.0 * i0) + abs(i3 + i4 - 2.0 * i0)) / max(i0, 1e-4);
float depthEdge = smoothstep(0.035, 0.09, de);
```

雨丝、玻璃、光晕这些半透明物体放在单独的图层里，不进法线通道，也不写深度，所以不会被描边。透过玻璃看到的店内货架，轮廓线依然清晰。

## 湿地面：实时镜面反射

雨夜画面一半的气氛来自地面。这里没有用贴图假装，而是真的做了反射：

1. **镜像相机**：把主相机沿地面翻到地下，渲染一张倒影图。这和 three.js 的 `Reflector` 用的是同一套做法，用斜裁剪平面把地面以下的东西裁掉。
2. **竖向拉丝**：雨中的柏油路，倒影总是被拉成一条条竖线。我沿着竖直方向对倒影做 14 次采样再加权平均，粗糙的地方拉得长，积水的地方拉得短。
3. **积水遮罩**：用一张 Canvas 画出积水和零散的湿斑。积水处几乎是镜面，其余地方只有淡淡的反光。
4. **涟漪扰动**：用几组正弦波扰动采样坐标，倒影会跟着水面轻轻晃动。

```glsl
float wet = texture2D(tWet, vW.xz / (uHalf * 2.0) + 0.5).r;  // 0 = 只是打湿，1 = 积水
vec2 uv = vP.xy / vP.w + n * mix(0.0035, 0.0018, wet);       // 涟漪扰动
float rough = mix(0.05, 0.008, wet);                          // 积水越深，拉丝越短
for (int i = 0; i < 14; i++) {
  float f = float(i) / 13.0;
  float k = 1.0 - f * 0.8;
  acc += texture2D(tRefl, uv + vec2(0.0, (f - 0.2) * rough)).rgb * k;
  ws += k;
}
```

反射以叠加的方式混合，所以只有亮的东西（招牌、橱窗、信号灯）会在地面上留下倒影，暗处保持暗。另外，每个光源脚下还有一条始终朝向镜头的光带，补上动画里那种夸张的高光。

## 雨：会落在正确的表面上

4200 根雨丝用一个 `LineSegments` 绘制，每帧在 CPU 上更新位置。每根雨丝出生时都会查一次自己正下方是什么：

```js
function surfaceY(x, z) {
  if (x > -4.2 && x < 1.4 && z > -4.4 && z < 1.2) return 3.5;   // 便利店屋顶
  if (x > -2.45 && x < 1.45 && z >= 1.2 && z < 2.15) return 2.3; // 雨棚
  if (x < -5.4 && z < 1.2) return 5.6;                           // 隔壁楼顶
  if (x > -5.4 && x < 1.4 && z < 1.2) return 0.1;                // 小巷
  return onSidewalk(x, z) ? SW : 0.0;                            // 人行道 / 车道
}
```

所以雨不会穿过屋顶落进店里，雨棚下面是干的。落到地面的雨滴有约三分之一会溅起 3 颗水花，一部分还会生成一圈涟漪。涟漪是 140 个圆环组成的实例化网格，大小和透明度由一个「年龄」属性控制。

雨丝和水花的颜色在着色器里实时计算：顶点着色器遍历场景里的 9 个主要光源，按距离衰减累加颜色。经过路灯的雨就是暖白色，经过招牌附近就带一点青色。信号灯变色时，附近的雨也跟着变。

## 光只从玻璃透出来

店里的两盏点光源都开了阴影。墙会挡光，玻璃不挡，所以店里的光只能从橱窗透到人行道上，窗框和货架的影子也会投到地面上。不开阴影的话，店里的光会直接穿墙照亮隔壁的楼。

## 那些小动效

- **屋檐滴水**：雨棚边缘有 8 个滴水点。水珠先在檐口慢慢鼓起，再按自由落体掉到地面，溅起涟漪。
- **玻璃水痕**：橱窗用一个着色器画出往下滑的水珠和拖尾，再加上静止的小水珠和斜向的反光。
- **自动门**：每 12 秒开合一次，开门时门口的暖光会亮一点。
- **招牌闪烁**：平时有极轻微的电流抖动，每隔几秒随机闪一下。招牌对应的地面倒影也跟着闪。
- **信号灯**：16 秒一个周期，两个方向交替。行人信号灯在变红前会闪烁。
- **生活细节**：隔壁二楼的窗户里有电视的蓝光在跳，关东煮上方飘着蒸汽，香烟铺拉着卷帘门，公告栏上贴着「迷い猫」的寻猫启事。

## 移轴：让它看起来像桌上的模型

最后一步是让画面「变小」。真实的微缩模型照片景深很浅：对焦平面以外的东西很快就虚了。最终合成时，我根据深度和对焦距离（相机到旋转中心的距离）算出每个像素的模糊半径，再叠加一个画面上下边缘更虚的移轴遮罩，用 28 次黄金角螺旋采样做散景模糊：

```glsl
float coc(vec2 uv){
  float d = min(lin(uv), uFocus * 2.5);
  float c = clamp(abs(d - uFocus) / uFocus * 2.4 - 0.1, 0.0, 1.0);
  float tilt = smoothstep(0.18, 0.5, abs(uv.y - 0.48));  // 上下边缘更虚
  return clamp(max(c, tilt * 0.85), 0.0, 1.0);
}
```

再加上一点边缘色散、冷暖分离调色和胶片颗粒，画面就有了「被定格下来的动画截图」那种质感。

## 过曝：从 8 位换成 HDR 管线

第一版上线后，在真机上看，店门口、自动贩卖机和路灯下的斑马线都白成了一片。原因是中间结果存在 8 位的渲染目标里：店内灯光、窗口光晕、地面反射叠加起来超过 1.0 的部分全被截断成纯白，泛光再把这些纯白扩散出去。

修法是标准的 HDR 流程：

1. 颜色、反射、合成这几张渲染目标改用半精度浮点（`HalfFloatType`），超过 1.0 的亮度被完整保留下来。
2. 泛光的阈值提到 0.95，只有真正的高光才会发光。
3. 最终合成时用 ACES 曲线做色调映射，把高光柔和地压回显示范围，暗部也多了一点层次：

```glsl
vec3 aces(vec3 x){
  return clamp((x * (2.51 * x + 0.03)) / (x * (2.43 * x + 0.59) + 0.14), 0.0, 1.0);
}
col = aces(col * uExposure);
```

另外把几个本来就设得太强的光晕（贩卖机、招牌、橱窗）调低了一半以上，斑马线的白色也压暗了一点。

## 街坊们

便利店的名字叫「あまやどり」，日语里是「避雨」的意思，所以 NPC 也围绕「雨夜里的便利店」来设计：

- **店员**：站在收银台后面，自动门一开就鞠躬，算是「いらっしゃいませ」。
- **两位客人**：一个在货架前挑零食，时不时伸手拿东西；一个在收银台前排队结账。
- **避雨的女学生**：站在雨棚下低头看手机，手机屏幕会照亮她的脸。每隔一会儿抬头看看雨停了没有。
- **黄色雨衣的人**：在自动贩卖机前按按钮、弯腰取饮料，然后站着喝一口。
- **撑透明伞的路人**：从小巷走出来，沿人行道拐过街角，再从底座边缘走出去。踩到积水会溅起涟漪，雨落在伞面上会溅起水花，伞下面是干的。
- **出租车**：车头灯照亮湿漉漉的路面，地面倒影也会跟着移动；遇到红灯会减速停在停止线前，绿灯再开走。
- **黑猫**：蹲在香烟铺的卷帘门前甩尾巴，眼睛在夜里反光。公告栏上那张「迷い猫」寻猫启事找的大概就是它。

人物全部由胶囊体和球体拼成，四肢和上半身各有一个关节，动作都是用正弦曲线写的程序动画。会走出底座的路人和出租车用了局部裁剪平面：只渲染底座范围以内的部分，所以看起来像从模型的截面里走进走出，而不是悬在半空。

## 小结

| 项目 | 数据 |
| --- | --- |
| 代码量 | 约 1800 行，单个 HTML 文件 |
| 外部资源 | 只有 Three.js r147 及其轨道控制器、泛光后期脚本，场景本身不用任何模型和图片 |
| 贴图 | 全部用 Canvas 现画：招牌、海报、自动贩卖机、饮料柜、路面标线等 |
| 每帧渲染 | 阴影 13 次 + 法线、镜像、颜色各 1 次 + 后期约 15 次 |
| 角色 | 6 个人、1 辆出租车、1 只猫，全部是程序动画 |

如果要上线到真正的产品里，第一件事是做减法：把镜像反射降到半分辨率、关掉店内点光源阴影、去掉超采样，帧率能翻好几倍，画面观感损失并不大。不过这次就让它全开吧。
